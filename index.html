Acesso ao aplicativo

Entre com o login e a senha fornecidos pelo administrador. Novos acessos são criados somente pelo administrador.

Selecione uma empresa

Como administrador, você pode abrir uma das empresas disponíveis.

Alterar minha senha

Informe sua senha atual e escolha uma nova senha com pelo menos 8 caracteres.

Configuração

Exporte uma cópia dos dados ou importe um arquivo JSON para substituir os dados atuais.

Backup e restauração

Exporte seus dados para guardá-los ou transferi-los para outro navegador. A importação substitui os dados atuais e, quando conectado, sincroniza a substituição com o Supabase.

Logins e acessos

Crie logins, defina as empresas liberadas e gerencie permissões. Os usuários também podem alterar a própria senha pelo botão no cabeçalho.
